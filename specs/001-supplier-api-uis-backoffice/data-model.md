# Data Model: supplier-api-uis-backoffice

## Entities

### Supplier
Represents a carrier/logistics partner.

- `id`: integer (auto-generated by TinyDB)
- `name`: string
- `country`: string
- `categories`: list of strings
- `cost_per_kg`: float (must be > 0)
- `status`: string (enum: "active", "suspended")
- `updated_at`: string (ISO 8601 timestamp)
